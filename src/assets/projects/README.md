# Screenshot Projek — `src/assets/projects/`

Simpan screenshot projek (T-Medic, QuizSep, dst.) di folder ini.

## Aturan
- Format **WebP** atau **PNG**, target rasio **16:10** atau **16:9** (card memakai `object-fit: cover`).
- Kompres supaya < ~300KB.
- Nama file cocokkan dengan field `image` di `src/data/projects.js`.

Sampai screenshot asli tersedia, kartu menampilkan placeholder bertema.
